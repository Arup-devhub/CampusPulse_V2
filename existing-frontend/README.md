# CampusPulse Frontend

A polished React + Vite + TypeScript frontend prototype derived from the CampusPulse PRD.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Included UX
- Placement command dashboard
- Student/company readiness intelligence
- Skill-gap analytics
- College workshop intervention flow
- Placement drives
- Assessments + proctoring signals
- JD-based resume intelligence
- Placement reports
- Responsive sidebar/navigation
- Student / Placement Admin / Recruiter role preview

## Backend integration
Replace mock data and handlers with the PRD REST endpoints under `/api/v1`.
The UI intentionally keeps readiness explanations and intervention metrics visible instead of using excessive AI visual effects, matching the PRD's UI/UX requirements.
